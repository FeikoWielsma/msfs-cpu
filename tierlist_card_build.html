Reading the matrix

1080p and 1440p take the same parts on purpose. The cheapest current 16 GB cards already cover both, so there is no real hardware difference to draw — what changes is what those parts deliver, and the index chips show it: a 9060 XT reads 63 at 1080p but 54 at 1440p. Only 4K moves the picks, where that same card falls to 41 and the entry build has to step up.

Diminishing returns are visible in the chips. At 1080p the jump from mid to high buys +6 index points for about €360, because the GPU field compresses to a 5.5× spread there and the CPU is the limit. At 4K the spread opens to 17× and the same money matters far more. AMD's high-end build repeats at every resolution — the 9070 XT is its ceiling, and past that you are into a 5090.

Measured: CPU index from seven Tom's Hardware, PCGH and ComputerBase test passes; GPU index per resolution from Tom's Hardware. Relative scales, not frame rates. Judgement: which CPU pairs with which resolution — CPU tests run at low resolution to isolate the chip, so there is only one CPU ladder. Not measured: RAM and storage.
Prices are indicative EUR, Netherlands, as of — check before buying. They include PSU, case and motherboard.
