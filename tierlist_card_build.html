Reading the matrix

Memory is the story in 2026, and it decides the entry platform. 32 GB of DDR5 is €400 against €240 for DDR4 — so entry stays on AM4 and LGA1700 deliberately. Nobody puts €400 of memory in an €1,100 build. Mid and high move to DDR5 where the platform earns it. Nothing takes 64 GB: that kit now costs more than a 9800X3D.

Cheapest way into V-Cache: a Ryzen 5 5500X3D, about €150. AliExpress only — there is no retail channel — and no benchmark set here covers it, so it gets no index chip and no row. For scale, a 5600X3D reads 61 and the 5500X3D clocks lower, so expect a little under that. On a €240 DDR4 kit it is a lot of cache for the money.

Intel's ladder is flat for this game, so don't climb it. A 250K Plus (€219) scores 76 and a 285K (€549) scores 78 — €330 for two index points, which is why the 285K appears nowhere on this card. The Intel column tops out at a 270K Plus and spends the rest on the GPU. AMD's ladder is not flat: a 9800X3D reaches 97.

1080p and 1440p take the same parts on purpose. The cheapest current 16 GB cards cover both, so the difference shows in the index chips — a 9060 XT reads 63 at 1080p but 54 at 1440p — rather than in invented picks. Only 4K moves them, where that card falls to 41. AMD's high-end build repeats at every resolution: the 9070 XT is its ceiling, and past that you are into a 5090.

Measured: CPU index from seven Tom's Hardware, PCGH and ComputerBase test passes; GPU index per resolution from Tom's Hardware. Relative scales, not frame rates. Judgement: which CPU pairs with which resolution — CPU tests run at low resolution to isolate the chip, so there is only one CPU ladder. Not measured: RAM and storage.
